This chapter gives you an overview of the most important functions you will need during the creation of your thesis. There will be a lot of examples on how to insert figures, write mathematical expressions, create references, etc.\\
In case you need a more detailed explanation on several \gls{latex} commands, we advise you to check out \textsc{Overleaf}'s documentation of \gls{latex} at \cite{Overleaf}.
\section{Document structure}
Your thesis has to be logically divided into chapters, sections, sub-sections, etc.\\
To ensure that all chapters and sections are correctly displayed in the table of contents, you need to label them accordingly, using commands like \texttt{\textbackslash chapter\{\}}, \texttt{\textbackslash section\{\}}, \texttt{\textbackslash subsection\{\}}, etc.
\subsection{Hierarchical structure}
In \gls{latex}, the hierarchical structure of a document is organized using chapters, sections, subsections, and subsubsections.
The most relevant commands and their usage are explained below.
\begin{itemize}
\item \texttt{\textbackslash chapter\{chapter title\}}: Top-level sectioning command. Typically used for main chapters in a thesis.
    \item \texttt{\textbackslash section\{section title\}}: Subdivision of a chapter. Used for major sections within a chapter.
    \item \texttt{\textbackslash subsection\{subsection title\}}: Subdivision of a section. Used for smaller sections within a major section.
    \item \texttt{\textbackslash subsubsection\{subsubsection title\}}: Subdivision of a subsection. Used for detailed subsections within a subsection.
\end{itemize}
\subsection{Labeling and Cross-Referencing}
To label chapters, sections, subsections, and subsubsections for cross-referencing, you use the \texttt{\textbackslash label\{\}} command. You can then reference these labels anywhere in your document using the \texttt{\textbackslash ref\{\}} or \texttt{\textbackslash pageref\{\}} commands.
\subsubsection{Labeling}
\label{subsubsec:labeling}
Here is an example of how to label chapters or sections:
\begin{verbatim}
\chapter{Introduction}
\label{ch:introduction}

\section{Inserting Figures, Subplots, etc.}
\textbackslash label{sec:insert-figures}

\subsection{Inserting Two Figures Stacked Vertically}
\label{subsec:insert-stacked}
\end{verbatim}
\subsubsection{Cross-referencing}
\label{subsubsec:cross-ref}
Here is an example of how to reference the labeled chapters or sections in the text:\\

\section{Inserting Figures, Subplots, etc.}
\label{sec:insert-figures}
To insert a figure in \gls{latex}, we need to include the \texttt{graphicx} package. This package is already included in our \texttt{packages.tex} file. In the following sections, you will learn how to insert figures in different ways.

\subsection{Inserting a Single Figure}
\label{subsec:insert-single-fig}
You can use the \texttt{figure} environment with the \texttt{\textbackslash includegraphics} command to insert a single figure. Here's an example:

\begin{verbatim}
\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.5\textwidth]{path/to/your/image.png}
    \caption{Example figure}
    \label{fig:single}
\end{figure}
\end{verbatim}

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.4\textwidth]{Figs/Logo_Farbe_weiß_Text.png}
    \caption{Example figure}
    \label{fig:single}
\end{figure}

\textbf{Explanation} of the individual commands:
\begin{itemize}
    \item \texttt{\textbackslash beginfigure}: Creates figure enviorment.
    \item \texttt{[htbp]}: Placement specifier (here, top, bottom, page).
    \item \texttt{\textbackslash centering}: Centers the figure.
    \item \texttt{\textbackslash includegraphics[width=0.5\textbackslash textwidth]\{path/to/your/image.png\}}: Adds the image which ist stored at \textit{path/to/your/image.png} and adjusts the width of the image to 50\% of the text width.
    \item \texttt{\textbackslash caption\{\}}: Adds a caption below the figure.
    \item \texttt{\textbackslash label\{\}}: Adds a label for referencing the figure.
\end{itemize}

This \gls{latex}-code will insert a single figure with the caption `Example figure' and a label for cross-referencing. You can reference a figure using the \texttt{\textbackslash ref\{fig:label\}} command, where you insert the actual label you gave the figure you want to reference.
In Fig.~\ref{fig:single}, you can see how the code from above will look when applied in \gls{latex}.


\subsection{Inserting Two Figures Side by Side}
\label{subsec:insert-side-by-side}
You can use the \texttt{subfigure} package to insert two figures side by side. Here's an example:

\begin{verbatim}
\begin{figure}[htbp]
    \centering
    \begin{subfigure}[b]{0.4\textwidth}
        \includegraphics[width=\textwidth]{path/to/your/image-a.png}
        \caption{Figure A}
        \label{fig:subfiga}
    \end{subfigure}
    \hspace{0.05\textwidth}
    \begin{subfigure}[b]{0.4\textwidth}
        \includegraphics[width=\textwidth]{path/to/your/image-b.png}
        \caption{Figure B}
        \label{fig:subfigb}
    \end{subfigure}
    \caption{Two figures side by side}
    \label{fig:sidebyside}
\end{figure}
\end{verbatim}

\begin{figure}[htbp]
    \centering
    \begin{subfigure}[b]{0.4\textwidth}
        \includegraphics[width=\textwidth]{Figs/Logo_Farbe_weiß_Text.png}
        \caption{Figure A}
        \label{fig:subfiga}
    \end{subfigure}
    \hspace{0.05\textwidth}
    \begin{subfigure}[b]{0.4\textwidth}
        \includegraphics[width=\textwidth]{Figs/Logo_s_weiß_Text.png}
        \caption{Figure B}
        \label{fig:subfigb}
    \end{subfigure}
    \caption{Two figures side by side}
    \label{fig:sidebyside}
\end{figure}

\textbf{Explanation:}
\begin{itemize}
    \item \textbf{\texttt{\textbackslash begin\{subfigure\}[b]\{0.4\textbackslash textwidth\}}}: Creates a subfigure occupying $40$\% of the text width.
    \item \textbf{\texttt{\textbackslash hspace\{0.05\textbackslash textwidth\}}}: Adds horizontal space of 5\% of the textwidth between the subfigures.
\end{itemize}
This code will insert two figures side by side with captions `Figure A' and `Figure B' and a common caption `Two figures side by side'.

\end{verbatim}

\begin{figure}[htbp]

This will insert two figures stacked vertically with captions `Figure A' and `Figure B' and a common caption `Two figures stacked vertically'. You can reference each subfigure by itself by using its labels or you can reference both figures at once by using their common label.

\section{Tables}
\label{sec:insert-tables}
To create a simple table, use the \texttt{table} as well as the \texttt{tabular} environment.
\subsection{Basic Table Creation}
The code example below, shows how to generate a simple table. Here the structure of your commands is important.
\begin{verbatim}
\begin{table}[h]
    \centering
    \begin{tabular}{ccc}
    \hline
    Header 1 & Header 2 & Header 3 \\
    \hline
    Row 1, Col 1 & Row 1, Col 2 & Row 1, Col 3 \\
    Row 2, Col 1 & Row 2, Col 2 & Row 2, Col 3 \\
    \hline
    \end{tabular}
    \caption{A simple table}
    \label{tab:simple}
\end{table}
\end{verbatim}
\begin{table}[htbp]
    \centering
    \begin{tabular}{ccc}
    \hline
    Header 1 & Header 2 & Header 3 \\
    \hline
    Row 1, Col 1 & Row 1, Col 2 & Row 1, Col 3 \\
    Row 2, Col 1 & Row 2, Col 2 & Row 2, Col 3 \\
    \hline
    \end{tabular}
    \caption{A simple table}
    \label{tab:simple}
\end{table}
\textbf{Explanation} of the individual commands:
\begin{itemize}
    \item \textbf{\textbackslash begin{table}[h]}: Creates a table environment. [h] specifies that the table should be placed "here" in the file.
    \item \textbf{\textbackslash centering}: Centers the table.
    \item \textbf{\textbackslash hline}: Inserts a horizontal line in-between the rows.
    \item \textbf{\&}: Separates columns within a row.
    \item \textbf{\textbackslash\textbackslash}: Ends the current row. 
    \item \textbf{\textbackslash caption\{...\}}: Adds a caption to the table.
    \item \textbf{\textbackslash label\{...\}}: Adds a label for referencing the table with \textbackslash ref\{\}.
\end{itemize}

\subsection{Table Formatting}
\label{subsec:format-tables}
You can adjust column alignment and add more complex formatting. This can be done by adding an alignment specifier and vertical bars | for vertical lines to the tabular command, as can be seen in the code example below.
\begin{verbatim}
\begin{table}[h]
\centering
\begin{tabular}{l|c|r}
Left-aligned & Center-aligned & Right-aligned \\
\hline
Data 1 & Data 2 & Data 3 \\
Data 4 & Data 5 & Data 6 \\
\end{tabular}
\caption{Formatted table}
\label{tab:formatted}
\end{table}
\end{verbatim}

\begin{table}[!htbp]
\centering
\begin{tabular}{l|c|r}
Left-aligned & Center-aligned & Right-aligned \\
\hline
Data 1 & Data 2 & Data 3 \\
Data 4 & Data 5 & Data 6 \\
\end{tabular}
\caption{Formatted table}
\label{tab:formatted}
\end{table}
\newpage
\textbf{Explanation}:
\begin{itemize}
    \item \textbf{l}: Left-aligns the column.
    \item \textbf{c}: Center-aligns the column.
    \item \textbf{r}: Right-aligns the column.
    \item \textbf{|}: Adds vertical line.
\end{itemize}

\subsection{Adding Multi-row and Multi-column}
You can also add multirows or multicolumns to your table by using the commands seen in the code example below.
\begin{verbatim}
\begin{table}[h]
    \centering
    \begin{tabular}{|c|c|c|}
    \hline
    \multirow{2}{*}{Multi-row} & Col 1 & Col 2 \\
    & Col 3 & Col 4 \\
    \hline
    Col 1 & \multicolumn{2}{|c|}{Multi-column} \\
    \hline
    \end{tabular}
\caption{Table with multi-row and multi-column}
\label{tab:multi}
\end{table}
\end{verbatim}
This is what the code example from above looks like when compiled:
\begin{table}[htbp]
    \centering
    \begin{tabular}{|c|c|c|}
    \hline
    \multirow{2}{*}{Multi-row} & Col 1 & Col 2 \\
    & Col 3 & Col 4 \\
    \hline
    Col 1 & \multicolumn{2}{|c|}{Multi-column} \\
    \hline
    \end{tabular}
\caption{Table with multi-row and multi-column}
\label{tab:multi}
\end{table}

\textbf{Explanation}:
\begin{itemize}
    \item \textbf{\textbackslash usepackage{multirow}}: Import the multirow package.
    \item \textbf{\textbackslash multirow\{2\}\{*\}\{Multi-row\}}: Spans the content `Multi-row' over 2 rows. The * denotes the natural width.
    \item \textbf{\textbackslash multicolumn\{2\}\{|c|\}\{Multi-column\}}: Spans the content `Multi-column' over 2 columns, with centered alignment and vertical lines on either side.
\end{itemize}

\section{Mathematics}
\label{sec:math}
When writing mathematical symbols or expressions, you need to do so in a mathematical environment. For this, you need the\textit{amsmath} package and its offered commands.\\
To display a mathematical expression correctly you need to wrap them in a mathematical environment. This can be established in several ways. Here are some ways with which you can enable the so-called \textit{Math mode}:
\begin{itemize}
    \item \$....\$ or \textbackslash( ....\textbackslash): These commands are used for in-line math (i.e. writing mathemtical symbols or expressions). They are used when including mathematical expressions in flow text. Both commands achieve the same result.

    Example: \begin{quote}
    To calculate the parameter $\lambda$ we need to determine the circular-frequency $\omega$ and phase shift $\varphi$.'
    \end{quote}
    
    \item \textbackslash[ ....\textbackslash]: This command is used for writing equations without numbering/labeling them. It goes into a new line and centers the equation (it's not centred here because we're in an itemise environment, but in normal text it is.).

    Example: \begin{quote}
    `The mass-energy equivalence is stated by the equation \[E=mc^2,\] which was discovered by Albert Einstein.'
    \end{quote}

    \item \textbackslash begin\{equation\} ... \textbackslash end\{equation\}: This command is used for equations. It goes to a newline and centers equations with label.

    Example:
    \begin{equation}
    \frac{\diff y}{\diff x} = \frac{\diff y}{\diff g} \cdot \frac{\diff g}{\diff x}
    \end{equation}


    This environment automatically numbers your equations in chronological order. If you want your equation to not be numbered, use equation* (with an asterisk) otherwise. 	
    
    Example:
    \begin{equation*}
    \frac{\diff y}{\diff x} = \frac{\diff y}{\diff g} \cdot \frac{\diff g}{\diff x}
    \end{equation*}

    \item \textbackslash begin\{align\} ... \textbackslash end\{align\}: This command is used if there are several equations that you need to align vertically. It goes to a new line and centers equations. 

    Example: \begin{quote}
    Our calculations yield the following system of equations:
    \begin{align} 
    2x - 5y &=  8 \\ 
    3x + 9y &=  -12\\
    6x + 4y &=  45
    \end{align}
    \end{quote}
    Like the \textit{equation}-environment, the \textit{align}-environment automatically numbers each line of your equations. If you want your equations not to be numbered, use equation* (with an asterisk) otherwise.\\

    \item \textbackslash begin\{multline\} ... \textbackslash end\{multline\}: This command is used, for equations that are longer than a line. Insert a double backslash to set a point for the equation to be broken. The first part will be aligned to the left and the second part will be displayed in the next line and aligned to the right.\\
    \\
    Again, the use of an asterisk * in the environment name determines whether the equation is numbered or not.
    
    Example:
    \begin{multline}
    p(x) = 3x^6 + 14x^5y + 590x^4y^2 + 19x^3y^3\\ 
    - 12x^2y^4 - 12xy^5 + 2y^6 - a^3b^3
    \end{multline}
\end{itemize}

\subsection{Macros}
To make the writing of equations faster and easier, this template provides several macros which are shortened versions of frequently used mathematical LaTeX functions.
The definition of these macros can be found in the \texttt{macros.tex} file.
Feel free to add your own macros for e.g. defining variables that are used multiple times throughout the document.
\subsubsection{\textbackslash mrm\{\}}
To avoid text in a mathematical env to become \textit{cursive}, use the macro-command \texttt{\textbackslash mrm\{\}} which we provide in this template (see \texttt{macros.tex}).\\
Without \texttt{\textbackslash mrm\{\}}:\\
\noindent\hspace*{15mm}$V_{pp} = 6 V$\\
With \texttt{\textbackslash mrm\{\}}:\\
\noindent\hspace*{15mm}$V_\mrm{pp} = 6\mrm{V}$\\
This should be remembered because only variables should be written in cursive. In this case, neither the subscript "pp" or the unit V is a variable, so it shouldn't be cursive. This macro is a short version of the LaTeX function \texttt{\textbackslash mathremove\{\}}.
\subsubsection{\textbackslash diff}
When writing a derivation we differentiate between a full derivation and a partial derivation. 
The full derivation is denoted with the letter d. This can be written in a math environment by using the macro \texttt{\textbackslash diff}.\\
For example:
\begin{align*}    
\frac{\diff Q}{\diff t} = \frac{\diff s}{\diff t}
\end{align*}
The partial derivation is denoted with the symbol $\partial$.  by using the LaTeX function \texttt{\textbackslash partial}.\\
For example:
\begin{align*}    
\frac{\partial Q}{\partial t} = \frac{\partial s}{\partial t}
\end{align*}
\subsubsection{\textbackslash RE, \textbackslash IM}
To denote the real-valued part of a complex-valued variable, the symbol $\RE$ is used. This can be written in a math environment by using the macro \texttt{\textbackslash RE}.
To denote the imaginary-valued part of a complex-valued variable, the symbol $\IM$ is used. This can be written in a math environment by using the macro \texttt{\textbackslash IM}.\\
Example:
\begin{align*}
    |z| = \sqrt{\RE(z)^2 + \IM(z)^2}
\end{align*}
\subsubsection{\textbackslash J}
The imaginary unit is either denoted by the symbol $\J$ or $\mrm{i}$. In electrical engineering, $\J$ is more common. Because $\J$ is not a variable, it is not written in cursive. The macro \texttt{\dateseparator J} enables us to use $\J$ in a mathematical environment.\\
Example:
\begin{align*}
    z = a + \J b
\end{align*}
\subsubsection{\textbackslash T}
A transposed vector is denoted with the letter T in superscript. To write this in a mathematical environment the macro \texttt{\textbackslash T} can be used.\\
Example:
\begin{align*}
    (A + B)^{\T} = A^{\T} + B^{\T}
\end{align*}
\subsubsection{\textbackslash COS,\textbackslash SIN}
To add cos and sin with large brackets in a mathematical environment, we can use the \texttt{\textbackslash COS\{\}} or \texttt{\textbackslash SIN\{\}} macro.
\begin{align*}
    \COS{\dfrac{\omega}{\omega_{0}}}
\end{align*}

\section{Citations and Bibliography}
You can manage your citations and bibliographies by using the \texttt{bibliography} and \texttt{bibtex} commands. 

\subsection{Including Citations in Your Document}
This subsection will show you how to add citations in your LaTeX document.

First, you need to create a \texttt{.bib} file, containing your bibliography entries, i.e. your sources.
Bib-entries are written in \textsc{BibTex} format and might look like this:

\begin{verbatim}
@typeofmedia{key,
  title={Title of cited word},
  author={Author1, Author2, et al.},
  year={Year in which work was published},
  publisher={Name of Publisher}
}
\end{verbatim}
\textbf{Explanation:}
\begin{itemize}
    \item  \textbf{\texttt{\textbackslash cite\{key\}}}: This command is used to cite a source from your Bib-file.
    \item \textbf{\texttt{key}}: is the keyword which you give your citation to reference it in your text.
    \item \textbf{\texttt{typeofmedia}}: This should be replaced with the actual type of media your source is(book, article, journal, etc.)
    \item Fields like \textbf{\texttt{title, author, year}}, and \textbf{\texttt{publisher}} describe the source and have to be filled accordingly.
\end{itemize}
Depending on your citation style, (which can be set with the command \texttt{\textbackslash bibliographystyle\{\}} in the \texttt{main.tex} file, the citations in your text might look like this: \cite{knuth1984texbook}.\\
The bibliography is automatically added by using the command \texttt{\textbackslash bibliography{file.bib}} in the \texttt{main.tex} file.\\
As an example, we provided a Bib-file called \texttt{sample.bib}, which contains example entries in different forms.
Instead of typing the bibliography file entries manually, you can usually automatically get them from major publication search engines like Google Scholar or IEEE Xplore.
For both of them, just click on the \textit{cite} button, select \textit{BibTeX} and copy the entry to your bibliography file.

\section{Glossary}
A glossary is a section at the end of a written work that defines confusing, technical, or advanced words. It is not mandatory to include a glossary in your thesis, but if you want to include one, here is how.\\
First, you create a new \texttt{tex}-file in which you write your glossary entries. 
In \gls{latex} you can define a glossary entry the following way:
\begin{verbatim}
\newglossaryentry{latex}{
    name=LaTeX,
    description={A document preparation system for high-quality typesetting}
}
\end{verbatim}
\textbf{Explanation:}
\begin{itemize}
    \item \textbf{label}: The first parameter is the label of this term and is used to reference it within the document with the gls command. In the example from above the label is `latex'. 
    \item \textbf{name}: The name parameter includes the word to be defined, in this case, `LaTeX'.
    \item \textbf{description}: Includes the definition of the current term.
\end{itemize} 
You can also define acronyms you use in your thesis. To do this, you open the \texttt{tex}-file containing your glossary entries and then define your acronym the following way:
\begin{verbatim}
    \newacronym{rms}{RMS}{Root Mean Squared}
\end{verbatim}
The structure is the same as of the \texttt{\textbackslash newglossaryentry}. Here, the \textbf{label} is \texttt{rms}, the \textbf{name} is \texttt{RMS} and the \textbf{description} is \texttt{Root Mean Squared}.\\
\newline
To include the \texttt{glossary.tex} file in your thesis, you use the command \texttt{\textbackslash input\{glossary\_filename\}}. Here, you have to replace the \texttt{glossary\_filename} parameter with the actual filename of the \texttt{tex}-file containing your glossary. This is already defined in the  \texttt{main.tex} file in line 56.\\
\newline
To print your glossary you have to use the command \texttt{\textbackslash printglossary} at the position in your thesis at which you want the glossary to be. We inserted it at the beginning of the thesis (before the table of contents).\\
If you have acronyms that you want to include, you use an additional keyword with the previous command:  \texttt{\textbackslash printglossary[type=\textbackslash acronymtype]}.\\
\subsection{Use Glossary entries in the text}
After you have defined the terms, to use them while you are typing your \gls{latex} file use one of the commands described below:
\begin{itemize}
    \item \textbf{\texttt{\textbackslash gls\{ \}}}: This prints the term in lowercase.\\ Example: \texttt{\textbackslash gls\{maths\}} prints `mathematics' when used.
    
    \item \textbf{\texttt{\textbackslash Gls\{ \}}}: This prints the term lowercase with the first letter printed in uppercase.\\
    Example: \texttt{\textbackslash Gls\{maths\}} prints `Mathematics'.
    
    \item \textbf{\texttt{\textbackslash glspl\{ \}}}: This prints the term in lowercase and puts it in its plural form.\\ Example: \texttt{\textbackslash glspl\{formula\}} prints `formulas'.
    
    \item \textbf{\texttt{\textbackslash Glspl\{ \}}}: This prints the term with the first letter in uppercase and puts it in its plural form.\\ Example: \texttt{\textbackslash Glspl\{formula\}} prints `Formulas'.
\end{itemize}
Including your terms in your text, using the commands from above may look something like this:\\
In this thesis, we will use \gls{latex} to prepare a high-quality document. The \Gls{latex} typesetting markup language is especially suitable 
for documents that include \gls{maths}. \Glspl{formula} are rendered 
easily once one gets used to the commands.
