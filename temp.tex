Ihr Ausgangspunkt, ist zuerst den nächsten Zustand, hervorgerufen durch $u[k|k-1] = \Delta u[k|k-1] + u[k-1|k-2]$, zu schätzen und basierend darauf die Prädiktion anzusetzen:
\[
\hat{\bm{x}}[k+1|k] = \Aw \bm{x}[k] + \bm{B}\bm{u}[k|k-1] + \Ew
\]
\[
\Bar{\boldsymbol{y}}[k+2|k] = { \Tilde{\boldsymbol{P}}_{x} \hat{\bm{x}}[k+1|k] 
	+ \Tilde{\boldsymbol{P}}_u \boldsymbol{u}[k|k-1] + \Tilde{\boldsymbol{P}}_{E}{\boldsymbol{E}}(\omega[k]) }+ \Tilde{\boldsymbol{P}}_{\Bar{\Delta u}} {\Bar{\boldsymbol{\Delta u}}}[k+1|k] 
\]
Während mein ursprünglicher Ansatz gewesen wäre, das $\hat{{x}}[k+1|k] $ implizit über die Prädiktionsmatrizen, basierend auf dem echten Messwert $ {x}[k]$ zu rechnen. \\
Daher war mein Ansatz:

\begin{equation}
\Bar{\boldsymbol{y}}[k+2|k] = { \Tilde{\boldsymbol{P}}_{x} {\boldsymbol{x}}[k]
	+ \Tilde{\boldsymbol{P}}_u \boldsymbol{u}[k-1|k-2] + \Tilde{\boldsymbol{P}}_{E}{\boldsymbol{E}}({\omega}[k]) } + \Tilde{\boldsymbol{P}}_{\Bar{\Delta u}} {\Bar{\boldsymbol{\Delta u}}}[k+1|k] 
	\label{equ:2_prediction_dtc}
\end{equation}
